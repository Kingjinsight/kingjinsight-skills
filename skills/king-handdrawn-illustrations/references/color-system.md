# 配色系统

## King Quiet 固定色板

| 颜色 | 色值 | 职责 |
|---|---|---|
| 炭黑 | `#242629` | 线稿、主要文字、结构和物件 |
| 深海蓝 | `#2E486E` | King 的 T 恤、品牌锚点、核心系统 |
| 柔珊瑚 | `#DF7565` | 问题、冲突、警告、关键结果 |
| 旧金黄 | `#D3AD58` | 路径、行动、进展、能量 |
| 柔鼠尾草 | `#7FA294` | 反馈、AI 协助、稳定状态、第二层信息 |
| 暖骨白 | `#F3EDE4` | King 的裤子、少量物件填色 |
| 纯白 | `#FFFFFF` | 唯一背景色 |

## 使用规则

- 每张固定使用炭黑、纯白、深海蓝。
- 每张默认只选择柔珊瑚、旧金黄、柔鼠尾草中的一种功能强调色。
- 只有“问题走向解决”这类需要同时表达两种状态的画面，才使用两种功能强调色。
- 彩色面积控制在约 15%–20%；深海蓝始终是最大彩色面积。
- 深海蓝主要用于人物和少量核心锚点，不涂满大面积背景。
- 暖骨白只做局部填色，绝不能替代纯白背景。
- 颜色表达职责，不做装饰性彩虹。
- 中文正文优先炭黑；彩色只用于短批注、圈线、箭头和状态标记。
- 长期识别依赖稳定重复：King 的深海蓝 T 恤不可漂移，柔鼠尾草是默认辅助色，柔珊瑚和旧金黄只在语义需要时出现。

## 选择逻辑

- 日常知识、沉淀、稳定：深海蓝 + 柔鼠尾草。
- 流程、移动、进展：深海蓝 + 旧金黄。
- 问题、断点、反差：深海蓝 + 柔珊瑚。
- 问题走向解决：柔珊瑚表示问题，柔鼠尾草表示稳定结果；主路径仍用炭黑。

## 失败信号

- 背景发黄或发灰。
- 每个物件一种颜色。
- 柔珊瑚大面积铺底。
- 旧金黄承担普通说明文字。
- 柔鼠尾草与深海蓝不分职责。
- 人物 T 恤颜色漂移。
