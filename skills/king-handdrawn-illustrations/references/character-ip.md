# King 人物 IP

## 身份

King 是固定视觉主角：安静、理性、好奇、亲自解决问题的年轻创作者。参考 `assets/character-reference.jpg` 校准身份。

参考图只定义人物，不定义六宫格构图。生成正文配图时，重新设计姿态、视角、动作和场景。

## 固定识别点

- 约 3.5–4 头身，年轻成人比例，不是幼儿比例。
- 蓬松短发，轮廓略乱，头顶有一撮向侧上方翘起。
- 黑色竖椭圆眼睛，间距自然。
- 省略或弱化鼻子。
- 小而克制的嘴，常用平静、思考、轻微困惑表情。
- 深海蓝宽松圆领 T 恤。
- 暖骨白九分宽松裤。
- 简洁圆头运动鞋。
- 炭黑细线，轻微手绘抖动。
- 脸、手臂和腿通常保留白底，不加肤色大面积填充。

发型、眼睛、T 恤和体态是最高优先级。物件遮挡时，至少保留两个强识别点。

## 性格

- 安静但不消极。
- 聪明但不端着。
- 认真做事，场景略荒诞。
- 遇到问题会亲手拆、接、修、试。
- 情绪克制，允许困惑、疲惫、专注和微小成就感。

## 动作原则

King 必须改变画面状态：

- 拉、扛、塞、捞、压、称、缝、剪、拧。
- 守、推、接、拆、标记、回收、记录、试验。
- 卡在结构里、修补断点、扶住失衡物、从怪装置中取出结果。

如果去掉 King，画面核心隐喻仍完全成立，说明人物只是装饰；重写构图。

## 可用物件

优先低科技、可触摸物件：

- 纸箱、抽屉、旧机器、漏斗、秤、邮筒。
- 门、井、梯子、水管、线团、闸门、转盘。
- 黑盒、打孔器、压面机、晾衣绳、怪工位。
- 杯子、笔记本、纸片、胶带、螺丝和扳手。

每张只选 1–2 个主物件。

## 禁止

- 巨大闪亮眼睛、腮红、猫耳、爱心、星星眼。
- 过度夸张表情、幼儿动作、卖萌姿势。
- 西装、复杂潮服、盔甲或频繁改变服装。
- 写实人像、日漫精修、3D 公仔、商业吉祥物。
- 只站在角落、指向图表、举牌讲解。
- 把人物画成明显儿童。

## 一致性修复顺序

人物漂移时，按顺序修：

1. 发型轮廓。
2. 黑色椭圆眼与克制嘴型。
3. 深海蓝宽松 T 恤。
4. 3.5–4 头身比例。
5. 暖骨白九分裤与圆头运动鞋。
